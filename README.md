# Modest Fashion E-Commerce Platform

This is a premium, custom-built e-commerce platform for Modest Fashion wear, featuring a fully functional storefront and a comprehensive Admin Panel for managing products, orders, customers, and more.

## Tech Stack
- Frontend: Next.js (App Router), React, TypeScript
- Styling: Tailwind CSS v4

## Running Locally

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the Storefront.
Navigate to [http://localhost:3000/admin/dashboard](http://localhost:3000/admin/dashboard) to view the Admin Panel.

## Project Structure
- `src/app`: Contains all Next.js application routes (Storefront & Admin).
- `src/components`: Reusable UI components and layout blocks.
- `public`: Static assets and images.
